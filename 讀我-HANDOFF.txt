★ 怎麼跑 / 測 / 部署
  npm install
  npm test              # test/rules.mjs 45 項 + test/daily.mjs 129 項
  npm run serve         # http://localhost:8801(另一個視窗)
  npm run check         # 真瀏覽器冒煙 40 項(含全螢幕 6 項 + 📡 打點 2 項 + 悔棋前回一般模式 1 項)
  CHECK_URL=https://incandescent-stroopwafel-31007a.pages.dev npm run check
  部署(⚠ 兩步,而且 --branch main 不能省,否則只建 preview):
  npm run stage
  npx wrangler pages deploy .deploy --project-name incandescent-stroopwafel-31007a --branch main
  改任何檔先 bump sw.js 的 CACHE_NAME(現在 xiangqi-3d-shell-v5);新增上線檔要補 scripts/stage.mjs SHIP + sw.js ASSETS_TO_CACHE。
  線上驗收看內容:
  curl -s "https://incandescent-stroopwafel-31007a.pages.dev/sw.js?bust=1" | grep "CACHE_NAME ="
